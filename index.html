About Teacher

오션중학교 정보 선생님을 소개합니다

단순히 프로그래밍 문법을 암기하는 것이 아닌, 컴퓨팅 사고력을 통해 일상의 문제를 해결하는 능력을 기르는 것을 목표로 합니다. 학생들 각자의 잠재력을 깨우는 재미있는 정보 수업을 지향합니다.

창의적 문제해결

정답을 찾는 것을 넘어, 다양한 방법으로 문제에 접근하고 스스로 해결책을 설계하는 힘을 기릅니다.

재미있는 실습 위주

이론 중심의 딱딱한 수업에서 벗어나, 직접 만지고 움직이는 피지컬 컴퓨팅으로 즐겁게 배웁니다.

협업과 소통

친구들과 아이디어를 나누고 함께 프로젝트를 완성하며 디지털 시대의 필수 역량인 협업 능력을 배양합니다.

class CodingClub:
    def __init__(self, student):
        self.student = student
        self.passion = 100
        self.skills = []

    def join_club(self):
        print(f"환영합니다! {self.student}님!")
        
    def learn_and_grow(self):
        while True:
            self.passion += 10
            self.skills.append('Creativity')
            if self.passion > 9999:
                return "미래의 혁신가 탄생!"
